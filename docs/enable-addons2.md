

# 🧩 Enabling Add-ons

**Add-ons extend Sunbird's core functionality. They are optional, independently deployable, and can be installed at any time after the base installation is complete.**

---

## How It Works

When you run the base `install.sh`, it provisions your cloud infrastructure and deploys all core Sunbird services. As part of that process, it also generates `addons/global-cloud-values.yaml` — a file containing cloud-specific values (storage endpoints, keys, etc.) that add-ons depend on.

Once the base install is complete, add-ons can be deployed independently using their own `addon.sh` script. Each add-on's script picks up the values already generated by the base install and deploys the add-on's Helm charts onto the running cluster.

```
Run install.sh
    → Provisions infrastructure
    → Deploys core services
    → Generates addons/global-cloud-values.yaml
            ↓
export ENV_NAME=<your-environment>
            ↓
cd addons/<addon-name>
./script/addon.sh install [azure|gcp]
    → Deploys add-on Helm charts using existing values
```

> [!NOTE]
> Add-ons do not require a separate OpenTofu or infrastructure provisioning step. Everything they need is already in place after `install.sh` completes.

---

## Prerequisites

Before installing any add-on, make sure the following are in place:

- ✅ Base `install.sh` has completed successfully
- ✅ Core Sunbird services are running (Elasticsearch, Redis, Kafka, YugabyteDB)
- ✅ `kubectl` is configured and connected to the cluster
- ✅ `helm` 3.x is installed
- ✅ `ENV_NAME` environment variable is set to your environment name

To set `ENV_NAME`:

```bash
export ENV_NAME=<your-environment>   # e.g. demo, dev, staging
```

## Installation

All add-ons follow the same installation pattern.

### DIAL

Provides QR code creation, linking, and management for learning content. Deploys two components — `dial` and `dialcode-context-updater`.

```bash
cd addons/dial
./script/addon.sh install [azure|gcp]
```

### Discussion Forum

Adds community discussion threads and group management to the platform, powered by NodeBB. Deploys three components — `discussionmw`, `nodebb`, and `groups`.

```bash
cd addons/discussion-forum
./script/addon.sh install [azure|gcp]
```

### Video Stream Generator

Handles video transcoding and HLS stream generation using Azure Media Services or AWS Elemental MediaConvert.

```bash
cd addons/video-stream-generator
./script/addon.sh install [azure|gcp]
```

> [!NOTE]
> The cloud provider argument defaults to `azure` if not specified.

### Verifying the installation

After installing an add-on, confirm the pods are running:

```bash
kubectl get pods -n sunbird
```

---

## Uninstalling an Add-on

To remove an add-on, run the uninstall command from its directory:

```bash
cd addons/<addon-name>
./script/addon.sh uninstall [azure|gcp]
```

> [!CAUTION]
> Uninstalling an add-on removes its Helm releases from the cluster. Any data associated with the add-on may be lost. Make sure you have backups before proceeding.
